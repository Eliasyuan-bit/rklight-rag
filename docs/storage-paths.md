# 项目存储路径约定

本项目在开发机、162 中转/固件编译机及板端均不把项目文件写入 `/tmp`。这包括下载、编译中间物、传输暂存、测试产物、日志和 PID 文件。运行第三方工具前，设置 `TMPDIR`、`TMP` 和 `TEMP` 指向受控目录；不能控制其临时写入位置时，先停止执行并核对。

| 机器 | 临时与中间产物 | 持久产物 |
| --- | --- | --- |
| 本项目开发机 | 仓库 `runtime/tmp/` | 源码、文档、发布包各归其目录；`runtime/` 不提交 Git |
| 162 中转/固件编译机 | `/home/rockchip-yn/data/rklight-rag-stage/` | SDK 构建产物保留在其 `output/` 或明确命名的发布目录 |
| RK3588 板端 | `/userdata/rklight-rag/runtime/` | 程序在 `/userdata/rklight-rag/`，模型在各模型目录 |

`/userdata/lightrag-data/` 是现有知识库目录，包含已建好的 UCM630x 数据。它不属于临时目录或固件程序文件；不得在构建、安装、升级、测试和清理过程中删除、覆盖、重建或纳入全量刷写。新固件的功能测试使用独立测试目录或另一块空白板。

162 上旧固件的 `package-file` 包含 `userdata.img`。这种全量 `update.img` 不能直接作为当前板的保库升级包。出厂镜像与保留 `/userdata` 的升级包必须分别制作和验证。

此约定不要求清理已有 `/tmp` 内容；已有文件可能属于其他任务或系统进程。
